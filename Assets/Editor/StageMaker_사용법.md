# Stage Maker 사용법

메뉴 `DebugRush > Stage Maker`

## 화면
- 왼쪽: 학년 탭, 스테이지 목록 (초록 = 있음, 회색 = 비어 있음. 회색 누르면 새로 만듦)
- 가운데: 도구 버튼 + 맵 (기본 30×16칸, 오른쪽에서 크기 변경)
- 오른쪽: 스테이지 정보 입력

## 맵 그리기
- 벽: 클릭 / 드래그
- 지우개 또는 우클릭: 지우기
- 재료대·제작대·시작점: 클릭한 위치로 이동
- 단말기: 클릭마다 추가 (최대 4)
- 벌: 최대 2
- 이동: 놓인 물체 드래그
- 맵 아래 빨간 글씨가 있으면 배치 수정 필요
- 왼쪽 아래 빨간 구역은 보유 자료 UI 자리라 물체 놓지 않기

## 위 버튼
| 버튼 | 기능 |
|---|---|
| 새 스테이지 / 복제 / 삭제 | 삭제는 확인창 뜸 |
| 자동 생성 | 외곽 벽 + 랜덤 배치 (누를 때마다 바뀜) |
| 기본 배치 | 기본 맵으로 되돌림 |
| 되돌리기 | Ctrl+Z |
| 저장 | 저장 + 맵 화면에 등록 |
| ▶ 플레이 | 바로 테스트 |

## 참고
- 제한시간은 쉬움 기준 ×1.3 (1학년 = 쉬움)
- 벌 패턴: 노란 버튼만 사용
- 저장 위치: `Assets/DebugRush/Data/Stage_학년_번호.asset`
