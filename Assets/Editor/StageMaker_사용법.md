# Stage Maker 사용법 (1장)

**여는 법:** Unity 위 메뉴 `DebugRush > Stage Maker`. 창 하나로 끝. 씬·폴더 안 열어도 됨.

```
┌──────────────────────────────────────────────────────────────────────────────┐
│ [＋새 스테이지][복제][삭제]  [자동 생성][기본 배치][되돌리기]  [저장][▶플레이] │ ← ① 툴바
├────────────┬─────────────────────────────────────────┬───────────────────────┤
│ 1학년|2|3  │ [이동][벽][지우개][기획][프로][그래][QA] │ 스테이지 이름 [_____] │
│ ┌────────┐ │ [제작대][단말기][시작점][벌]   ← ③ 팔레트 │ 한 줄 요약   [_____] │
│ │1-1 완성│ │ ┌─────────────────────────────────────┐ │ 제한시간 [1]분 [50]초 │
│ │1-2 완성│ │ │ ■■■■■■■■■■■■■■■■■■■■■■■■■■■■ │ │ 단말기 목표 쉬움/보통/ │
│ │1-3 ... │ │ │ ■  [그래픽] [QA]        단말기  ■ │ │ 어려움 슬라이더       │
│ │1-6 비어│ │ │ ■     ■■■■  [제작대]  ■■■■     ■ │ │ 벌 패턴 [A-1][A-2].. │
```

## 새 스테이지 만들기 (5단계)
1. **②** 학년 탭 → 회색 "비어 있음" 카드 클릭 (또는 **＋ 새 스테이지**). 앞 스테이지 배치를 복사해서 생김.
2. **자동 생성** 한 번 누르면 외곽 벽 + 랜덤 배치. 마음에 안 들면 또 누르기 (누를 때마다 다름).
3. **③ 팔레트**에서 고르고 격자에 그리기
   - **벽**: 클릭 / 끌면 쭉 칠해짐 · **우클릭** = 지우기 (어떤 도구든)
   - **재료대·제작대·시작점**: 클릭한 자리로 이동 (하나씩만 있음)
   - **단말기**: 클릭할 때마다 하나 추가 (최대 4) · **벌**: 최대 2마리
   - **이동**: 이미 놓인 물체를 끌어서 옮기기
4. **⑤** 이름·요약·시간·목표·벌 패턴(노란색=켜짐)·대사 입력
5. **④**에 빨간 줄이 없으면 **저장** → **▶ 플레이**로 바로 해보기. 저장하면 맵 화면에 자동 등록.

## 알아둘 것
- 실수하면 **되돌리기** 또는 **Ctrl+Z**.
- **삭제**는 확인창이 뜸 (맵 화면에서도 빠짐).
- 벽은 그린 그대로 게임에서 보이고 막힘 (보이는 벽 = 막히는 벽).
- 방 크기는 28×12칸 고정. 바깥 한 줄은 벽으로 두기.
- 제한시간은 쉬움 기준 ×1.3 됨 (1학년 = 쉬움).
- 스테이지마다 따로 저장: `Assets/DebugRush/Data/Stage_학년_번호.asset`
