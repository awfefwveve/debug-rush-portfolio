# Stage Maker 사용법 (기획자용)

메뉴 **DebugRush > Stage Maker** 로 엽니다.

## 화면 구성
- **왼쪽**: 챕터 1~3 × 스테이지 1~10 버튼
  - 초록 = 플레이 가능 / 주황 = 에셋은 있지만 게임에 미등록 / 회색 = 없음 (맵에 "준비 중"으로 잠김)
- **오른쪽**: 선택한 스테이지 편집

## 새 스테이지 만들기
1. 왼쪽에서 회색 칸(예: 1-6)을 누릅니다.
2. **[새 스테이지 만들기]** → 바로 앞 스테이지의 수치·몬스터·배치를 복사해서 만들어지고, 게임에 자동 등록됩니다.
3. 오른쪽에서 내용을 고치고 **[저장]**.

## 편집 항목
| 항목 | 설명 |
|---|---|
| 표시 이름 / 요약 | 맵 화면 카드의 제목과 설명 |
| 제한시간 | 초 단위 (Normal 기준). 난이도별 배율은 Easy/Normal/Hard 순 |
| 단말기 목표 | 난이도별로 단말기 1대당 채워야 하는 게이지 칸 수 (2~8) |
| 몬스터 | 프리팹, 사용할 패턴 수(1~3), 등장 위치. 기획서 기준 스테이지당 1~2마리 |
| 시작/종료 대사 | 화자, 대사, 초상화(선택) |
| 배치 데이터 | 플레이어 시작 위치, 재료대 4개, 제작대, 단말기 위치(개수 = 목록 길이) |

## 맵 배치 바꾸기
1. **[Stage 씬 열기]**
2. 씬 뷰에서 재료대·제작대·단말기·플레이어를 드래그해서 옮깁니다.
   - 단말기를 늘리려면 BugTerminal을 Ctrl+D로 복제하고, StageManager의 **terminals** 목록에 추가합니다.
3. **[씬 배치를 이 스테이지에 저장]** → 배치가 스테이지 데이터에 저장됩니다.
4. **[씬 되돌리기]** 로 씬을 원래대로 돌려놓습니다. (Stage 씬 자체는 저장하지 마세요. 모든 스테이지가 같은 씬을 씁니다.)

- **[씬에 미리보기]**: 저장된 배치를 씬에 적용해서 확인합니다.
- 배치 데이터의 **use** 가 꺼져 있으면 Stage 씬의 기본 배치를 그대로 씁니다.

## 테스트
- **[▶ 이 스테이지 플레이]**: 저장 → Stage 씬 열기 → 바로 플레이.

## 잠금 규칙 (기획서 p.8, p.12)
- 게임에 등록된 스테이지만 맵에서 플레이 가능. 나머지는 "준비 중".
- 이전 스테이지를 클리어해야 다음 스테이지가 열립니다.
- 챕터 2·3의 첫 스테이지는 이전 챕터 10스테이지를 모두 클리어해야 열립니다.

## 확인 칸
몬스터 0마리 / 3마리 이상, 대사 없음, 단말기 개수 오류, 미등록 상태를 경고로 보여줍니다.
