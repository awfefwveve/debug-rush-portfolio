# Stage Maker 사용법

메뉴 `DebugRush > Stage Maker`

## 화면
- 왼쪽: 학년 탭, 스테이지 목록 (초록 = 있음, 회색 = 비어 있음. 회색 누르면 새로 만듦)
- 가운데: 도구 버튼 + 맵 (기본 30×16칸 = 화면에 딱 맞음. 오른쪽에서 크기 자유롭게 변경, 크면 게임 카메라가 알아서 멀어짐)
- 오른쪽: 스테이지 정보 입력

## 맵 그리기
- 벽: 클릭 / 드래그
- 바닥: 클릭 / 드래그로 칠하기. 바닥 없는 칸은 게임에서 빈 공간이라 못 들어감 (오른쪽 [바닥 전부 채우기], [바닥 둘레에 벽 두르기])
- 지우개 또는 우클릭: 물체 → 벽 → 바닥 순으로 지움 (방 밖에 나간 물체도 가능)
- 물체는 바닥 위에만 놓임
- 재료대(기획·프로그래밍·그래픽·QA)·제작대·단말기·벌: 클릭마다 하나씩 추가 (개수 제한 없음)
- 이미 놓인 물체를 같은 도구로 누르면 끌어서 이동
- 시작점: 클릭한 위치로 이동
- 벌을 클릭하면 오른쪽에서 그 벌만 공격 패턴 켜고 끄기 (아무 벌도 안 고르면 새 벌 기본값)
- 이동: 놓인 물체 드래그
- 맵 아래 빨간 글씨가 있으면 배치 수정 필요
- 왼쪽 아래 빨간 구역은 보유 자료 UI 자리라 물체 놓지 않기

## 위 버튼
| 버튼 | 기능 |
|---|---|
| 새 스테이지 / 복제 / 삭제 | 삭제는 확인창 뜸 |
| 자동 생성 | 외곽 벽 + 랜덤 배치 (누를 때마다 바뀜) |
| 기본 배치 | 기본 맵으로 되돌림 |
| 되돌리기 | Ctrl+Z |
| 저장 | 저장 + 맵 화면에 등록 |
| ▶ 플레이 | 바로 테스트 |

## 참고
- 제한시간은 쉬움 기준 ×1.3 (1학년 = 쉬움)
- 벌 패턴: 노란 버튼만 사용
- 저장 위치: `Assets/DebugRush/Data/Stage_학년_번호.asset`

## 스테이지 주고받기
- 기획자: 만든 스테이지 선택 → [내보내기] → `.stage` 파일을 개발자에게 전달
- 개발자: [가져오기] → 그 파일 선택 (같은 번호가 있으면 덮어쓰기/건너뛰기/빈 번호로 추가 선택)
- 스테이지 하나 = 파일 하나라 서로 다른 스테이지는 안 겹침
